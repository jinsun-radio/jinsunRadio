金孫收音機04
Constraints

四條不可違反的架構約束

1 隱私邊界

裝置↔雲端只傳事件，影像永不外傳；僅長輩主動語音求助那段才上雲 ASR。

2 長輩端無 UI

不用 App、不看螢幕。互動全靠語音、燈號、鈴聲與實體 SOS 按鈕。

3 升級時效

疑似跌倒 → 語音詢問 → 20 秒無回應即升級（推播家屬＋發派遣單）。

4 Excel 申報

社工後台必備 Excel 匯出，對接政府申報硬需求。

金孫收音機05
Sense · 感知層

國產晶片・隱私守在家

Himax WiseEye2

奇景光電｜跌倒視覺推論，影像不外傳、本地端運算。

Realtek AmebaPro2

瑞昱｜主控・麥克風・Wi-Fi・BLE 5.1 配網・TTS 發聲。

實測韌體 HUB8735 Ultra：按鈕錄音 → 雲端 ASR → LLM → 雲端 TTS 播放；上行 POST /voice、下行 MQTT 訂閱 jinsun/{serial}/cmd。

金孫收音機06
Decide · 決策層

雲端大腦：多 Agent × 狀態機

🧠 語音多 Agent

  • Intent 意圖分類
  • Emergency 緊急升級
  • Needs 需求解析
  • Conversation 陪伴
  • Device 裝置控制

⚙️ 派遣狀態機

事件分級・20 秒升級・就近派工・卡單改派・到場回報。

AWS 對應：IoT Core／API GW+Lambda／Step Functions／Bedrock·Transcribe·Polly／DynamoDB+Cognito。

現行原型：Supabase（即時同步真後端）＋ Node.js Agent server，介面設計成可平移 AWS。
